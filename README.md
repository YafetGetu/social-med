# Social Contacts Web Application

A React based web application that displays social contacts in a master detail view.

## Features

* Sidebar listing all contacts
* Online status indicators
* Main detail view for the selected profile
* Responsive layout

## Setup Instructions

1. Install dependencies using npm install
2. Run the development server using npm run dev
3. Open your browser to view the application

## Technologies Used

* React
* CSS
* JavaScript
